# Code of Conduct

We want this project to be a welcoming, practical place to collaborate.

- Be respectful and constructive.
- Discuss ideas and code, not people.
- Do not harass, threaten, discriminate, or publish another person's private information.
- Give maintainers time to review reports and contributions.

Maintainers may edit or remove content, or restrict participation, when behavior harms the community. Report sensitive conduct concerns privately using the contact method in [SECURITY.md](SECURITY.md). Other moderation questions may be opened as a GitHub issue.
